## 📝 Краткое описание

Консольное приложение для управления задачами, разработанное на Python с использованием:
- **ООП** (инкапсуляция, наследование, полиморфизм)
- **MVC** (Model-View-Controller)
- **Очереди** для сортировки задач по приоритету (High → Medium → Low)
- **Стека** для отмены последнего действия (Undo)
- **JSON** для сохранения и загрузки данных

Приложение позволяет добавлять, редактировать, удалять и фильтровать задачи, а также сохранять их в файл.
